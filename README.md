# BunkBuddy — Smart Attendance Planner

BunkBuddy helps college students track subject-wise attendance and understand the impact of missing upcoming classes.

## The problem
Students often have to calculate attendance manually, compare subject requirements, and estimate whether future absences will put them below the minimum threshold.

## Project goals
- Track attendance across subjects and class sessions.
- Organize a weekly timetable and academic calendar.
- Calculate safe absences and recovery requirements.
- Simulate future attendance scenarios, including mass bunks.
- Make data entry and planning intuitive.

## Planned implementation
A React and TypeScript frontend using Vite, with a reusable attendance calculation engine. Local persistence supports development; Supabase integration provides an optional cloud-backed workflow.

## Development milestones
1. Initialize the project and its documentation.
2. Build the typed data models, calculation engine, and persistence layer.
3. Implement the dashboard, timetable, attendance tracking, and onboarding screens.
4. Add simulation, analytics, import tools, and regression tests.
